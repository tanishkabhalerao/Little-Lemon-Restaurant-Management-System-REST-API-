# Little Lemon Restaurant Management System (REST API)

## Overview
A backend REST API for managing restaurant operations using Django REST Framework. The system allows customers to browse menus, place orders, and managers to manage restaurant operations through secure role-based access.

## Features
- User Registration & Login
- Token Authentication (Djoser)
- Role-Based Access Control
- Menu Management
- Category Management
- Shopping Cart
- Order Management
- Delivery Crew Assignment
- Pagination & Ordering
- Django Admin Panel

## Tech Stack
- Python
- Django
- Django REST Framework
- Djoser
- SQLite
- Git & GitHub

## User Roles
- Admin
- Manager
- Delivery Crew
- Customer
